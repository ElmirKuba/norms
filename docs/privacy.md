# Приватность

## MVP

- **Кто может создавать чаты:** все. Ограничений нет.
- **Видимость профиля:** всё видно всем. Поиск по аккаунтам (UIN / username) — глобальный.
- **Ссылок на профили нет** — прила, не веб. Доступ к аккаунтам только через поиск в приложении.
