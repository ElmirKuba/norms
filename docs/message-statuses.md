# Статусы сообщений

## Таблица статусов

| # | Иконка | Визуал | Значение | Статус |
|---|---|---|---|---|
| 0 | ⚠ | Восклицательный знак, без галочек | Ошибка отправки | `failed` |
| 1 | ✓ | Одна серая | На устройстве, ждёт ключ (не зашифровано) | `pending_key` |
| 2 | ✓ | Одна яркая (синяя) | Отправлено на сервер | `sent` |
| 3 | ✓✓ | Две тусклые | Доставлено на устройство получателя | `delivered` |
| 4 | ✓✓ | Две яркие (синие) | Прочитано | `read` |

## Детали

- **Цвет:** яркий синий (вдохновение — Telegram).
- **failed:** кнопка "повторить отправку" рядом с сообщением. Возникает в трёх случаях:
  - Обрыв WSS в момент отправки.
  - Сервер ответил ошибкой при отправке (любой 4xx/5xx кроме `chat_not_found`).
  - **`404 chat_not_found`** — сервер удалил чат каскадом (собеседник кикнул сессию или удалил аккаунт). В этом случае дополнительно к `failed` помечаем чат `is_dead = true` локально и блокируем дальнейшие попытки отправки. Подробнее: [`devices-and-chats.md`](devices-and-chats.md#мёртвые-чаты-на-устройстве-собеседника).
- **pending_key:** сообщение написано но чат ещё в статусе `pending_key` (обмен ключами не завершён). Зашифруется и отправится автоматически.
- **read-статус:** отключить нельзя. Упрощаем для MVP.
