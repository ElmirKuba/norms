# Сервер

## Принцип

**Транзитный — не хранилище.** Сервер доставляет, не читает и не хранит дольше необходимого.

## Что знает сервер

- Аккаунты (`accounts`, `uins`)
- Устройства/сессии (`sessions`: system_name, nickname, platform, refresh_token)
- Публичные ключи — **временно**, только на этапе обмена при создании чата
- Зашифрованные blob'ы сообщений — **временно**, до подтверждения доставки
- Метаданные чатов (название, пара устройств, статус)
- Инвайты, рефералы

## Что НЕ знает сервер

- Содержимое сообщений (только зашифрованный blob)
- Приватные ключи
- Локальные прозвища чужих устройств
- Историю переписки (после доставки blob удаляется)

## Транспорт

| Протокол | Что через него |
|---|---|
| HTTPS | Авторизация, регистрация, инвайты, обмен ключами, метаданные, feature flags |
| WSS | Сообщения реалтайм, доставка накопленных, статусы онлайн, статусы сообщений, кик устройств |

## Синхронизация при выходе онлайн

При подключении устройства по WSS:
1. Сервер находит все `pending_messages` для этой сессии.
2. Пушит их клиенту по WSS.
3. Клиент подтверждает получение каждого сообщения.
4. Сервер удаляет подтверждённые blob'ы.

Отдельного HTTP-эндпоинта для синхронизации нет — всё через WSS.
